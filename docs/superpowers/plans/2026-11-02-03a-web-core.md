# 計畫 3a：網站核心（瀏覽、學校頁、校系頁、比較、中英切換）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `web/` 建立以 Next.js 16 伺服器端渲染的雙語網站，讓訪客不需登入就能依地區瀏覽、搜尋、篩選台灣與美國的大學，看完整的學校頁與校系頁（錄取要求、歷年資料、強項、費用、來源），並把 2–4 個校系並排比較；同時修正管線在真實資料上發現的三個錯誤，並補上台灣校系的科系領域與公私立。

**Architecture:** 網站只讀資料庫：Drizzle ORM + postgres.js 以唯讀角色 `web_reader` 連線（migration 0006）。查詢分兩層：`src/lib/queries/*.ts` 是純查詢函式（可在 Vitest 以本機測試庫測試），`src/lib/data.ts` 用 `'use cache'` + `cacheLife('days')` 包裝供頁面使用。所有路由在 `src/app/[locale]/` 之下（根版面在此），`src/proxy.ts` 把沒有語言前綴的網址導到 `/zh` 或 `/en`，介面文字用官方的字典檔模式（不用 i18n 套件）。讀取 `searchParams` 的部分一律包在 `<Suspense>` 內。個人化資料（收藏、比較清單、地區偏好）只存在瀏覽器。

**Tech Stack:** Next.js 16.4.4（App Router、Cache Components、Turbopack）、React 19.3、TypeScript 5.9.3、Tailwind CSS 4（`@tailwindcss/turbopack`）、Drizzle ORM 0.45.4、postgres 3.4.9、Vitest 5、Playwright 1.64；管線部分沿用 Python 3.12 + uv + pytest。

## Global Constraints

- 每個資料區塊都顯示來源名稱（連到 `source.url` 或該列的 `source_url`）與抓取日期；日期格式 `YYYY-MM-DD`，時區 `Asia/Taipei`（設計文件 3、5.1.10）。
- 網站只讀資料庫，不寫入；正式環境以 `web_reader` 角色連線。`DATABASE_URL` 只在伺服器端使用，任何 Client Component 都不得 import `src/db/*` 或 `src/lib/queries/*`。
- 只顯示至少有一個 `program` 的 `institution`（計畫 1、2 約定）。歷年資料只顯示每個系列最近三個年度（設計文件 6.1.1）。
- 學校與校系原始名稱保留原文、不做機器翻譯：`zh` 顯示 `name_zh ?? name_en`；`en` 顯示 `name_en ?? name_zh`（台灣校系沒有英文名，英文介面顯示中文原名）。科系領域名稱取 `field.name_zh／name_en`。
- 語言：`zh`（預設，`<html lang="zh-Hant-TW">`）與 `en`（`<html lang="en">`），網址前綴 `/zh`、`/en`；兩份字典鍵值必須完全一致。
- 連結一律用 `institution.web_url`，不得用 `domain` 組網址（`domain` 可能含 `#`，計畫 2 約定）。
- 美國國際生學費以 `out_of_state` 顯示並標示「以州外學費估計」（計畫 2 約定）；台灣學校目前沒有學費資料，學費欄顯示「—」。
- 資料不足時顯示「資料不足」，不得留白或拋錯（設計文件 5.1.3 第 4 點的精神）。
- Next.js 16 規則（細節見慣例整理）：不得 export `dynamic`、`revalidate`、`dynamicParams`、`runtime`、`fetchCache`；讀 `searchParams`／`cookies()` 的元件必須在 `<Suspense>` 內；`generateStaticParams` 不得回傳空陣列；`notFound()` 必須在任何 `<Suspense>` 之外呼叫才會回 404；`'use cache'` 函式只收基本型別參數，回傳值不得含 `bigint`（數值一律轉成 `number`／`string`）。
- 支援手機寬度（360px 起），不得出現橫向捲動；表格在窄螢幕可在自身容器內橫向捲動。
- 只用免費方案；不新增任何付費服務。
- 版本固定：`next@16.4.4`、`react`／`react-dom` 與 scaffold 相同、`typescript@5.9.3`、`drizzle-orm@0.45.4`、`postgres@3.4.9`、`vitest@5.0.5`、`@playwright/test@1.64.1`。不使用 next-intl。

## Review Focus

1. 不存在或非數字的 id（`/zh/schools/abc`、`/zh/schools/999999`、`/zh/programs/0`）：必須回真正的 HTTP 404，不得回 200 或 500。（Task 6、7 的 e2e 測試）
2. 探索頁的怪參數（`page=-1`、`page=99999`、`field=xyz`、`region=jp`、`q` 含 `%`、`_`、超過 100 字）：參數被夾限或忽略，不得產生 SQL 錯誤；`%`／`_` 視為字面字元。（Task 5 測試）
3. 校系只有部分資料（只有考分會、只有甄選會分則沒有篩選結果、或都沒有；美國學校沒有 SAT／ACT）：該區塊顯示「資料不足」，其他區塊照常。（Task 6、7 測試）
4. 英文介面看台灣資料：校系只有中文名時顯示中文原名，不得空白。（Task 5、6 測試）
5. 比較頁 `ids` 含不存在的 id、重複、超過 4 個、非數字：去掉無效值、去重、最多取前 4 個；有效值少於 2 個時顯示說明而非空表。（Task 8 測試）

def test_web_reader_can_read_data_tables(db):
    db.execute("set local role web_reader")
    for t in ("institution", "program", "admission_stat", "admission_requirement", "cost",
              "strength", "field", "institution_stat", "source"):
        db.execute(f"select count(*) from {t}")

@pytest.mark.parametrize("table", ["fetch_log", "cac_fetch"])
def test_web_reader_cannot_read_private_tables(db, table):
    db.execute("set local role web_reader")
    with pytest.raises(psycopg.errors.InsufficientPrivilege):
        db.execute(f"select count(*) from {table}")

def test_web_reader_cannot_write(db):
    db.execute("set local role web_reader")
    with pytest.raises(psycopg.errors.InsufficientPrivilege):
        db.execute("insert into field(code,name_zh,name_en,sort) values ('x','x','x',99)")

def test_web_reader_is_not_privileged(db):
    row = db.execute("select rolsuper, rolbypassrls from pg_roles where rolname='web_reader'").fetchone()
    assert row == (False, False)
